# KS1 §2.9: Availability assessment at tender stage

Source: Foundation Change Spec, change 4. Paste §2.9 into KS1 and the boundary block into the AI Twin configuration.
This file is the reference copy; the Build Plan 2 documents themselves were not read or edited.

## KS1 section 2.9 (verbatim from the spec)

```
2.9  AVAILABILITY ASSESSMENT AT TENDER STAGE

At tender stage the agent performs a soft availability assessment. It reads
stock positions, inbound supply and lead times to determine whether a line is
deliverable within the construction programme, and records an INDICATIVE
source plan.

The agent does not reserve, allocate or commit stock at tender stage. No
warehouse or store inventory is encumbered by a tender that has not been
awarded.

On award, the indicative source plan is converted to a committed allocation
against the blanket order, and stock is encumbered at that point.

Rationale: reserving network stock against an unwon tender misstates
availability to every other live tender competing for the same inventory.
```

## AI Twin boundary block (mirror of §2.9)

```
BOUNDARY: AVAILABILITY AT TENDER STAGE
- You MAY read SPAIStockPosition (QtyOnHand, QtyAvailable, NextInboundQty, NextInboundDate),
  product lead times and the tender's call-up schedule dates.
- Every SPAILineSource you create at tender stage MUST have SPAISourcePlanType = Indicative
  (the column defaults to Indicative; never set Committed).
- You MUST NOT write SPAIStockPosition.SPAIQtyAllocated or change any stock quantity.
- Converting Indicative to Committed, and encumbering stock, happens only on award, through the
  no-AI award process (Build Plan 1 Step 9), never by you.
- If a line cannot be delivered within the programme from the indicative plan, escalate it;
  do not reserve stock to "hold" it.
```

## How the platform enforces it

| Rule | Where |
|---|---|
| Indicative by default | `SPAILineSource.SPAISourcePlanType` default = Indicative (5a1c0009-…-0001) |
| No committed source on an unwon tender | Verification query 6 in `tools/import/verify.py` (expects 0) |
| Commit on award only | Step 9 / BP8 award process (not built yet) |
